# Make the AI Judge Laugh: Developer Excuses

One funny single-line excuse a developer gives when code breaks in production — a fresh twist on the classic "it worked on my machine", pointing out that a laptop never has to survive 40,000 users hammering the same endpoint at once.

## Entry

```bash
python3 main.py
```
